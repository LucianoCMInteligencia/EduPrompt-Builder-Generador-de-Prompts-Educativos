# EduPrompt Builder – Generador de Prompts Educativos

Proyecto web ligero pensado para docentes y formadores que quieren crear **prompts efectivos** para usar con ChatGPT en la creación de material educativo.

## Descripción

EduPrompt Builder permite combinar:

- Rol / profesión
- Tema educativo
- Nivel educativo y audiencia
- Tipo de material
- Objetivo del aprendizaje
- Tono y estilo
- Elementos necesarios
- Frases gancho

## Uso

1. Abre index.html.
2. Rellena los campos.
3. Pulsa **Generar prompt**.
4. Copia el resultado.

## Despliegue en GitHub y Cloudflare

Compatible con Cloudflare Pages y GitHub Pages.
